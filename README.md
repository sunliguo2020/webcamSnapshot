# webcamSnapshot

网络摄像头批量截图工具，可从 CSV 读取设备信息并批量采集画面，帮助快速核对摄像头与实际监控场景。

## 支持的设备

- 海康威视摄像头
- 大华摄像头
- 支持 ONVIF 协议的网络摄像头
- 电脑连接的 USB 摄像头

## 功能

- 选择并预览摄像头 CSV 文件
- 自定义截图保存目录
- 配置水印文字、字体、字号、颜色、描边和位置
- 批量截图期间可暂停或继续
- 在界面中查看运行日志
- 查看任务结果，并打开截图目录

水印样式会自动保存；运行源码时保存在 `config/watermark.json`，打包版保存在用户的 `%APPDATA%\webcamSnapshot` 目录。
水印设置中可逐行编辑和删除文字，也可从常用数据列表添加文件名、IP、时间、摄像头信息、型号、MAC 或序列号。每行支持 `{filename}`、`{ip}`、`{time}`、`{camera_type}`、`{camera_index}`、`{model}`、`{mac}`、`{serial_number}` 或 `{serial}` 等模板字段；仅在模板使用设备型号、MAC 或序列号时访问大华设备管理接口，无法获取的字段显示为 `N/A`。

运行 `python make.py` 后可选择生成单文件版或目录版。发布目录版时，请将 `dist` 下带有“目录版”后缀的整个文件夹打包并在目标电脑解压，不要只复制其中的 EXE。

## 运行

项目使用 Python 和 Tkinter 图形界面。安装依赖后，从项目根目录启动：

```bash
python -m pip install -r requirements.txt
python main.py
```

## 摄像头 CSV 格式

网络摄像头列表使用 CSV 文件。首行必须包含 `ip` 和 `password` 两列，列名不区分大小写；其他列可按需添加。
大华设备的 HTTP 管理端口默认为 `80`；如设备使用其他端口，可增加 `http_port` 列供水印信息读取使用。

```csv
ip,password
192.168.1.100,admin123
192.168.1.101,password456
```

## 截图保存位置

截图保存到界面中选择的目录，并按日期和时间建立子目录。未指定保存目录时，网络摄像头截图默认按 CSV 文件名归类。

## 常见 ONVIF 端口参考

| 厂商 | 常见端口 |
| --- | ---: |
| 雄迈 | 8899 |
| 大华 | 80 |
| 海康威视 | 80 |

实际端口请以设备配置为准。

## 打包为 EXE

在项目根目录运行：

```bash
python make.py
```

按提示输入 `1` 生成单文件版，或输入 `2` 生成目录版。目录版启动时不会解压单文件 EXE 内的依赖，推荐用于遇到 OpenCV 解压失败的情况；交付时需包含整个目录。打包脚本默认禁用 UPX 压缩。
